# 🤖 Thinknyx AI Hub

Welcome to the **Thinknyx AI Hub**! This is a comprehensive, multipage Streamlit application designed to showcase the capabilities of Google's Gemini Models using the latest Google GenAI SDK. 

This project is built to be simple enough for teaching purposes, yet robust enough to demonstrate real-world AI applications like conversational memory, data analysis with dynamic chart generation, and text-to-image synthesis.

## 🌟 Features Overview

### 1. 💬 Chatbot
A fully conversational AI agent powered by Gemini. 
- Maintains conversation history using Streamlit's session state.
- Provides contextual responses.
- Allows model switching for different performance tiers (e.g., Flash vs Pro).

### 2. 📄 File Q&A (Data Chat & Chart Generator)
An advanced document and data analysis tool.
- **Upload Support:** Accepts CSV, Excel, Text, and Markdown files.
- **Data Preview:** Instantly previews datasets.
- **Dynamic Charting:** Ask the AI to plot your data (e.g., "Plot a bar chart of Sales by Region"). The app intelligently extracts Python code generated by Gemini and renders Streamlit/Plotly charts directly on the screen!

### 3. 🎨 Image Generator
A creative tool that transforms text prompts into images.
- Powered by Google's latest **Imagen 3** model.
- Supports aspect ratio selection.
- Allows direct downloading of generated images.

### 4. ⚙️ Settings
A centralized configuration dashboard.
- **API Management:** Securely input and store your Google API Key for the session.
- **Model Selection:** Choose exactly which Gemini or Imagen model you want to power each individual page.

---

## 🛠️ App Flow & Working Architecture

1. **Home Page (`app.py`):** Acts as the entry point, sets up the page configuration, displays a welcome message, and initializes default session states (like model selections).
2. **Pages Directory (`pages/`):** Streamlit automatically creates a sidebar navigation menu based on the Python files in this directory. Each file represents a standalone feature but shares the `st.session_state` and secrets.
3. **Session State:** Crucial for maintaining chat histories (`messages`, `file_messages`), API keys, and selected models across page navigations.
4. **Google GenAI SDK:** Uses the modern `google.genai.Client` to interact with the models securely and efficiently.

## 🚀 Installation and Setup

### Prerequisites
- Python 3.9 or higher installed on your system.
- A valid Google Gemini API Key. You can get one from [Google AI Studio](https://aistudio.google.com/).

### Step 1: Clone or Download the Repository
Navigate to the directory where this project is located:
```bash
cd /path/to/thinknyx_ai_chatbot
```

### Step 2: Install Dependencies
Install all required Python packages using `pip`:
```bash
pip install -r requirements.txt
```
*(Dependencies include: `streamlit`, `google-genai`, `pandas`, `matplotlib`, `plotly`, `pillow`)*

### Step 3: Configure API Key and Theme
1. Navigate to `.streamlit/secrets.toml`.
2. Replace `"YOUR_GOOGLE_API_KEY_HERE"` with your actual Google API Key:
   ```toml
   GOOGLE_API_KEY = "AIzaSyYourKey..."
   ```
*(Note: If you don't do this, you can also manually input the key on the Settings page while the app is running.)*

### Step 4: Run the Application
Start the Streamlit server:
```bash
streamlit run app.py
```

### Step 5: Explore!
The app will automatically open in your default web browser (usually at `http://localhost:8501`). Use the sidebar to navigate between the different features!
